About

ヤマダ アオイ

山田 葵

高校時代に1950〜90年代前半に制作された東欧を中心とした各国の映画ポスターに魅了され、グラフィックデザインへの関心を深めました。
その興味をきっかけに、デザイン学部に進学。大学では現代美術や映像表現にも関心を広げ、学部2年次にはドイツへ交換留学。
現地では趣味で続けていたサウンドプログラミングを軸に、映像制作を行いました。
帰国後は、アートギャラリーでのインターンや英語を用いた接客業などを経験。現在は、興味の幅をさらに広げながら、Web制作にも取り組んでおり、 約半年前からHTML/CSSの学習を開始し、Tailwind CSSやFigmaなども活用しています。
好奇心旺盛で「まずはやってみる」姿勢を大切にしながら、ジャンルやメディアを横断して制作を続けています。趣味は映画鑑賞、読書、ギター、散歩など多趣味で、多様な視点を取り入れた柔軟な表現を目指しています。

使用スキル

グラフィックツール：Adobe Illustrator / Photoshop / InDesign

Web制作：HTML / CSS / Tailwind CSS / Figma

ビジュアル・サウンド表現：Premiere / TouchDesigner / PureData
